# Le Délice — Restaurant Page

A dynamic, single-page restaurant web application built using pure JavaScript DOM manipulation, ES6 modules, and Webpack. Developed as part of **The Odin Project** JavaScript curriculum.

## 🚀 Live Demo
[View Live Preview](https://github.com/AliouSang/restaurant-page)

---

## 🛠️ Built With
* **JavaScript (ES6+)** – Modular code structure, factory functions/modules, and dynamic DOM manipulation.
* **Webpack 5** – Asset bundling, development server, and configuration (`html-webpack-plugin`, style/css loaders).
* **HTML5 & CSS3** – Semantic markup and custom styling using CSS Grid and Flexbox.
* **Git & GitHub** – Version control and deployment via GitHub Pages.
